# Справочник: Структуры данных и Алгоритмы (DSA)

---

## 1. Стек (Stack)

**Стек** — это линейная структура данных, работающая по принципу **LIFO** (*Last In, First Out* — «последним пришел, первым ушел»). 

В стеке доступ открыт только к одному элементу — к его вершине. Все операции добавления и удаления происходят исключительно с верхнего конца.

### Наглядные примеры из реальной жизни
* **Стопка тарелок или книг:** Чтобы взять тарелку снизу, сначала нужно снять все тарелки, положенные сверху последними.
* **Магазин (обойма) пистолета:** Патрон, который заряжают последним, выстреливает первым.
* **Гардеробный рожок для одежды:** Пальто, повешенное на вешалку последним в плотном ряду, снимается первым.

---

## 2. Очередь (Queue)

**Очередь** — это линейная структура данных, работающая по принципу **FIFO** (*First In, First Out* — «первым пришел, первым ушел»).

В классической очереди элементы добавляются с одного конца (в конец очереди), а извлекаются с другого (из начала очереди).

### Наглядные примеры из реальной жизни
* **Очередь в кассу магазина:** Кто первым подошел с товарами к кассиру, тот первым оплачивает и уходит.
* **Автомобильный туннель:** Машина, которая первой въехала в туннель с односторонним движением, первой из него выедет.
* **Конвейер на заводе:** Деталь, поступившая на ленту первой, первой доходит до конца сборки.

## 3. Алгоритмы сортировки

### Быстрая сортировка (Quick Sort)
**Быстрая сортировка** — это эффективный алгоритм общего назначения, работающий по принципу **«разделяй и властвуй»** (Divide and Conquer). 

#### Принцип работы:
1. Из массива выбирается опорный элемент (**pivot**), например, из середины.
2. Массив перераспределяется так, что элементы меньше опорного перемещаются влево, а больше или равные — вправо (схема разбиения).
3. Процесс рекурсивно повторяется для левой и правой частей.

* **Временная сложность:** 
  * В среднем / Лучший случай: $O(N \log N)$
  * Худший случай: $O(N^2)$ (если опорный элемент выбирается неудачно на отсортированном массиве)
* **Память:** $O(\log N)$ на стек рекурсии. Сортировка выполняется *in-place* (на месте, без копирования элементов в новые массивы).

---

### Карманная сортировка (Bucket Sort)
**Карманная (распределительная) сортировка** — алгоритм, основанный на распределении элементов по нескольким группам («карманам» или корзинам).

#### Принцип работы:
1. Создается фиксированное количество пустых карманов.
2. Каждому элементу массива вычисляется индекс кармана на основе его значения, после чего элемент помещается в соответствующий карман.
3. Каждый карман сортируется отдельно (например, другой сортировкой или рекурсивно).
4. Элементы извлекаются из карманов по порядку и объединяются в итоговый массив.

* **Временная сложность:**
  * В среднем / Лучший случай: $O(N + K)$, где $K$ — количество карманов (работает за линейное время при равномерном распределении).
  * Худший случай: $O(N^2)$ (если все элементы попали в один карман).
* **Память:** $O(N + K)$ (требует дополнительной памяти под карманы).

## 4. Алгоритмы поиска

### Последовательный (линейный) поиск (Linear Search)
**Последовательный поиск** — метод поиска элемента путем последовательного перебора всех элементов массива от начала до конца.

* **Условие применения:** Работает на **любых** массивах (как отсортированных, так и неотсортированных).
* **Временная сложность:**
  * Лучший случай: $O(1)$ (элемент лежит на первом месте).
  * В среднем / Худший случай: $O(N)$ (нужно проверить весь массив).

---

### Бинарный (двоичный) поиск (Binary Search)
**Бинарный поиск** — высокоэффективный алгоритм поиска элемента путем постоянного деления отсортированного диапазона пополам.

#### Принцип работы:
1. Берется элемент в середине текущего диапазона.
2. Если он равен искомому — поиск завершен.
3. Если искомое число меньше среднего — правая половина отбрасывается.
4. Если больше — отбрасывается левая половина.
5. Процесс повторяется для оставшейся половины.

* **Условие применения:** Работает **строго на отсортированных** массивах (или контейнерах).
* **Временная сложность:**
  * Лучший случай: $O(1)$
  * В среднем / Худший случай: $O(\log N)$ (например, для 1000 элементов потребуется не более 10 итераций).

---

### Понятие «Шаг» в алгоритмах поиска
**Шаг (или итерация)** — это единичное выполнение основного цикла алгоритма, за которое происходит одна проверка/сравнение элемента с искомым значением.

* **В линейном поиске:** 1 шаг = перенос указателя на следующий элемент и сравнение его с target ($1 \text{ шаг} = 1 \text{ элемент}$).
* **В бинарном поиске:** 1 шаг = вычисление индекса `mid`, сравнение `arr[mid]` с target и сокращение области поиска в 2 раза.
