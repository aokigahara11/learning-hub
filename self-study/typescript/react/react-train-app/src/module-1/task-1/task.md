# Практическое Задание 1 (Модуль 1): TodoList с фильтрацией и удалением

**Цель**: Закрепить работу с компонентами, типизацией Props, реактивным состоянием useState 
и иммутабельным обновлением массивов (.map(), .filter(), spread-оператор ...).

**Требования к функционалу:**
## 1. Создание и структура задачи:

### Каждая задача имеет тип ITask:

TypeScript
interface ITask {
  id: number
  title: string
  isCompleted: boolean
}

Форма с input и кнопкой «Добавить». Пустые задачи добавляться не должны.

## 2. Управление состоянием задач:

Переключение статуса: Клик по задаче меняет 
 с true на false и наоборот.

Удаление: У каждой задачи есть кнопка Удалить или ✕. Клик по ней полностью удаляет задачу из массива (через .filter()).

## 3. Фильтрация задач:

Добавь 3 кнопки переключателя фильтров: «Все», «Активные», «Завершенные».

Состояние текущего фильтра храни в отдельном useState<'all' | 'active' | 'completed'>('all').

Отображай только те задачи, которые соответствуют выбранному фильтру.

## 4. Архитектура компонентов:

Раздели приложение минимум на 2 файла-компонента:

**TodoList.tsx** — главный родительский компонент с логикой и состоянием.

**TodoItem.tsx** — дочерний компонент одной карточки задачи, принимающий через Props данные задачи и колбэки (onToggle, onDelete).
